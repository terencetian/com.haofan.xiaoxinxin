功能一览

不止是计时器，是一整套「时间值多少钱」的可视化

🕐

打卡计时

上班打卡后按秒累计今日到账，下班打卡停止并结算。

💰

金币进度条

进度 = 今日已赚 ÷ 日薪，金币压在进度条前端一路向前。

🎨

图标吸色

自动提取进度条图标的主色，染遍进度条与窗口背景。

📅

工作日自动计算

按 2026 国办法定节假日算出当月工作日，含调休补班。

⏱️

工时自定义

自定义上下班时间与休息时长，支持跨零点排班，还可填校正工时补记或核减。

▫️

迷你模式

收起成一条小胶囊：图标 + 进度条 + 金额，不挡桌面。

💵

状态栏常驻

菜单栏图标常驻，可显示实时金额与进度，右键出完整菜单。

📌

贴边收纳

小窗拖到屏幕边缘停住，自动收纳进状态栏，随取随用。

🎨

自定义图标

设置页里换上自己喜欢的进度条图标，吸色跟着变。

🧩

桌面小组件

内置 WidgetKit 扩展，工资进度直接上桌面。

安装

两分钟上手 · 也可以自己编译

1

下载安装包

到 Releases 下载 xiaoxinxin-v1.3.dmg，打开后把「小薪薪」拖进「应用程序」。

2

首次打开放行

应用为 ad-hoc 签名（未购买 Apple 开发者账号）。首次打开若提示无法验证：系统设置 → 隐私与安全性 → 底部点「仍要打开」。

3

或从源码构建

装好 Xcode Command Line Tools 后：git clone https://github.com/terencetian/com.haofan.xiaoxinxin.git，进目录执行 ./deploy.sh 一键构建、签名并安装。
