功能一览

不止是计时器，是一整套「时间值多少钱」的可视化

🕐

打卡计时

上班打卡后按秒累计今日到账，下班打卡停止并结算。

⏰

到点自动下班

到了计划下班时间自动打卡下班，忘了点也不会多算钱；不想要可在设置里关掉。

🌙

加班计费

下班后或过点再打卡自动识别为加班，首页亮起「加班中」，加班时长单独累计。

🌅

隔天自动重置

跨天自动清零今日到账与加班；如果当时还在计费，从零点重新起算新的一天。

📈

月度统计

首页直接看本月累计进账与本月加班时长，按天流水汇总，月初自动归零。

📋

流水明细

设置页按日期范围查询每天的到账与加班，忘了打卡可手动补记，记错可删除。

💰

金币进度条

进度 = 今日已赚 ÷ 日薪，金币压在进度条前端一路向前。

🎨

图标吸色

自动提取进度条图标的主色，染遍进度条与窗口背景；图标可在设置页换成自己喜欢的图。

📅

工作日自动计算

按 2026 国办法定节假日算出当月工作日，含调休补班。

⏱️

工时自定义

自定义上下班时间与休息时长，支持跨零点排班，还可填校正工时补记或核减。

🗂️

设置分区折叠

薪酬、工时、校正、外观、窗口、流水六大功能区，点标题展开，窗口跟着变高变矮。

▫️

迷你模式

收起成一条小胶囊：图标 + 进度条 + 金额，一键展回大窗。

💵

状态栏常驻

菜单栏图标常驻，可显示实时金额与进度，右键出完整菜单。

📌

贴边收纳

小窗拖到屏幕边缘停住，自动收纳进状态栏，随取随用。

🌗

深色模式

跟随系统在浅色与深色之间自动切换，玻璃质感与文字对比度都做过适配。

🧩

桌面小组件

内置 WidgetKit 扩展，工资进度直接上桌面。

安装

两分钟上手 · 也可以自己编译

1

下载安装包

到 Releases 下载 xiaoxinxin-v1.9.3.dmg，打开后把「小薪薪」拖进「应用程序」。

2

首次打开放行

应用为 ad-hoc 签名（未购买 Apple 开发者账号）。首次打开若提示无法验证：系统设置 → 隐私与安全性 → 底部点「仍要打开」。

3

或从源码构建

装好 Xcode Command Line Tools 后：git clone https://github.com/terencetian/com.haofan.xiaoxinxin.git，进目录执行 ./deploy.sh 一键构建、签名并安装。
